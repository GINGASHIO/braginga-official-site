# GINGA PRINT FACTORY

ブラジンガ合同会社 プリントショップOEM事業部「GINGA PRINT FACTORY」の公式サイトです。

## 構成

- `index.html`: トップページ
- `styles.css`: 白黒基調のデザイン、レスポンシブ、スクロール演出
- `script.js`: PRODUCTカードのデータ、メニュー、スクロール表示演出
- `assets/images/`: サイト掲載画像

## 更新方法

PRODUCTは `script.js` の `products` 配列から追加・更新できます。

CASEは `script.js` の `cases` 配列から追加・更新できます。公開許可を得た案件のみ掲載してください。

## 公開

静的HTMLサイトとしてCloudflare Pagesで配信します。`main` ブランチを公開用として運用します。
