# GINGA PRINT FACTORY

ブラジンガ合同会社 プリントショップOEM事業部「GINGA PRINT FACTORY」の公式サイトです。

## 構成

- `index.html`: トップページ
- `about/`, `products/`, `cases/`, `estimate/`, `trophy/`: 会社紹介・商品価格・制作実績・見積り・表彰品
- `styles.css`: 白黒基調のデザイン、レスポンシブ、スクロール演出
- `navigation.css` / `navigation.js`: 全6ページ共通のメニュー、現在地表示、スマホ開閉、読みやすさの調整
- `creative.css` / `creative.js`: ブランド演出、制作相談への固定リンク、実績ギャラリー
- `script.js`: PRODUCTカード、商品検索・絞り込み、見積り計算、スクロール表示演出
- `assets/images/`: サイト掲載画像

## 更新方法

PRODUCTは `script.js` の `products` 配列から追加・更新できます。

商品一覧と自動見積りは `estimate/estimate-data.js` の公開用データを参照します。卸価格や掛率は公開用ファイルに含めないでください。

ヘッダーはトップへ戻るブランドリンクと、特集コレクション・商品別・会社紹介・制作実績・注文の流れ・FAQ・見積もり・問い合わせを表示します。HTMLのリンクを変更するときは共通ナビを揃え、下層ページの相対パスにも注意してください。開閉動作は `navigation.js` に集約しています。

CASEは `script.js` の `cases` 配列から追加・更新できます。公開許可を得た案件のみ掲載してください。

## 公開

静的HTMLサイトをCloudflare Workersのアセット配信で公開します。Worker名は `braginga-official-site`、独自ドメインは `braginga.net` です。公開前に全6ページのPC・スマホ表示、ヘッダーの7リンク、商品検索から見積りまでの操作を確認します。

## 商品の探し方とトップページの案内（2026-11-12）
