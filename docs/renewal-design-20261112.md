# BRAGINGA リニューアル設計記録 — 2026-11-12

## 対象・現状・保全

最新の制作元を起点に、`codex/braginga-renewal-20261112` の独立したローカル作業版で改修する。元の未コミット・未追跡・無視対象ファイルとGit情報は改修前バックアップへ保全。公開版と最新ローカル版の画面は別々に記録し、混同しない。メールの実送信は行わない。

改修前の主要な問題：公開トップの実績カードが選択事例の位置へ直接着地せず、実績からの相談がトップへの戻りを要求していた。商品詳細・関連商品・見積もりへの引き継ぎは既存機能として存在するが、一覧の検索状態を保つ戻り導線と商品比較に改善余地があった。トップは大きな英文と汎用的な画像、重複する相談導線が中心で、スマホ固定CTAの内容被りがあった。最新制作元にある飲食店シーンと4つのトップバナーは公開版には未反映だった。

この文書は設計と参考確認の記録。画面・操作結果、改修前後の画像、品質点検、公開成否は別の検証記録で管理する。問い合わせへの到達性と実際の問い合わせ件数の改善を区別する。

## サイトマップと主要導線

- トップ → 特集コレクション → スポーツ特集／飲食店・販促・卒業記念などの絞り込み済み商品一覧。
- 商品一覧 → 商品詳細／最大3点の比較 → 商品を引き継いだ簡易見積もり／メール相談。
- トップの選択事例 → その事例のアンカー → 関連商品／事例を引き継いだ「似たものを相談する」。
- 商品詳細・実績・表彰品への直接訪問 → 当該ページの条件・関連情報 → 見積もり／相談。トップへの戻りを必須にしない。
- 一覧へ戻る操作では検索語・カテゴリー・用途条件を保持し、比較候補も同じブラウザーセッションで維持する。

既存のページURL、必要なアンカー、商品番号を保持する。商品情報と商品詳細は既存の共通データ・生成手順を正本とし、生成ページだけの変更で条件を分岐させない。

## 1. Scene構成

1. **実物を見せるヒーロー**：No.15のユニ型トートバッグを大きく、No.7のキーホルダーを脇に配置。同じ意匠が日常のグッズになる強みを「そのユニフォームを、毎日のグッズに。」で伝える。写真は実物で、比率・色・ロゴを保つ。短いサービス説明と2つの目的別入口を添える。
2. **用途を選ぶ特集**：承認済みの飲食店・販促・スポーツ・記念品バナーを入口に使う。単なる装飾として同じ画像カードを反復しない。
3. **写真から制作事例へ**：ユニフォーム意匠のトート・巾着・キーホルダーの展開を主事例にする。マスクとエコバッグの事例は異なる大きさ・配置で続ける。「用途・何を作ったか・写真で確認できる形や意匠」を説明し、未確認の成果・顧客規模・性能を加えない。
4. **商品条件を探す入口**：実写真付きの商品種別リンクを用意。価格・最低ロット・仕様・サイズ・納期は商品一覧／詳細の共通データで比較する。
5. **迷ったときの短い案内**：コンパクトな注文の流れ・FAQ・簡易見積もり／相談へ。既存アンカーを保持し、主CTAと補助導線の役割を明確にする。

## 2. Scroll Choreography

通常のブラウザースクロールを使用し、pin・スクロール乗っ取りは採用しない。ヒーローでは画面外へ進む割合に応じ、2つの写真を小さく逆方向へ動かして前後関係を示す。移動上限はPC14px、640px以下7px。見出し・説明・CTAは移動させず、読んでいる内容を隠さない。

サービスの文字帯は同じ幅の2組を連続移動させる。再進入で本文や写真を隠さず、通常の戻る操作でもすぐ読める。単調なfadeUpの連続は採用しない。商品一覧・FAQ・見積もりは情報を即時に表示する。

## 4. Mobile構成

375／390／430pxを優先する。サービス説明・日本語見出し → 横幅を使った実写真 → 短い補足 → 2つの目的別入口の順とし、PCの左右構図を縮小しない。PCは写真と文字の非対称な構図にする。

用途バナーはスマホ2列、商品条件は読める1列。**比較は選んだ商品のカードをスマホで縦積みにし、各カード内で参考上代／仮価格・最低ロット・サイズ・仕様・納期を同じ順に並べる。横方向への強制スクロールは採用しない。** PCでは横に候補を並べる。各候補から詳細・簡易見積もり・メール相談へ直接進め、最大3点と解除操作を明示する。

商品詳細では写真と発注条件を近づける。重複していた固定相談ドックは表示しない。タップ領域、日本語の折り返し、フォーカス、固定ヘッダーによるアンカー隠れを幅別に確認する。

## 5. CTA導線

| 場所 | 主アクション | 補助・引き継ぎ |
|---|---|---|
| トップ | 商品・価格を探す → 商品一覧 | つくるものから相談 → 相談欄。写真の制作例は該当事例へ |
| 特集 | 対象用途の商品を見る | スポーツは既存の専用ページを活かす。選択用途を一覧へ引き継ぐ |
| 一覧／比較 | 候補の詳細・簡易見積もりへ | 検索・比較状態を維持。0件から条件を解除できる |
| 商品詳細 | 選んだ商品で簡易見積もり | 選んだ商品のメール相談／関連商品。トップへ戻さない |
| 制作事例 | 制作物に対応する関連商品へ | 「似たものを相談する」で事例を相談欄へ引き継ぐ |
| 表彰品 | 必要条件を確認して相談 | 当該ページの文脈を保ち、個別確認条件を固定価格にしない |
| 簡易見積もり | 商品・数量・費用の確認 | 計算ルール、最低ロット判定、未入力費用の意味を維持。条件付きで相談へ |
| メール相談 | 分かる範囲の用途・数量・希望時期から本文を作る | 宛先は既存の `info@ginga-bra.com`。本文確認と入力保持。実送信は行わない |

正式な参考上代、BOSS承認済みの仮価格・仮最低ロット、個別確認を表示上も区別する。参考上代や納期を写真から推測しない。
